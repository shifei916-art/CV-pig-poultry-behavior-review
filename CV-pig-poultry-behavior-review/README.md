# Computer Vision-Based Behavior Monitoring in Pig and Poultry Production

This repository contains supporting materials for the review manuscript on computer vision-based behavior monitoring in pig and poultry production.

## Contents

- `search_strings/`: Database-specific search strategies for Web of Science Core Collection and Scopus.
- `records/`: Bibliometric record files used for screening and narrative synthesis.
- `screening/`: Screening flow counts used to construct the bibliometric corpus.
- `coding/`: Species-level and pipeline-stage coding schemes.
- `vosviewer/`: Files used for VOSviewer keyword co-occurrence analysis.
- `figure_data/`: Data used to generate bibliometric figures.

## Data description

The bibliometric corpus contains records published between 2002 and 2025 and was constructed from Web of Science Core Collection and Scopus. The final included corpus contains 827 records.

## Notes on database licensing

The full raw records exported from Web of Science Core Collection and Scopus are not redistributed in their original complete form because of database licensing restrictions. The files provided here include derived bibliometric metadata, screening information, coding categories, and figure data used to support the analyses reported in the manuscript.

## Code availability

No custom model-training code was generated in this review. Bibliometric visualization was conducted using VOSviewer.
